# Portfolio — Reine Esther Bengono

Portfolio numérique réalisé dans le cadre du cursus en **Génie Logiciel (Niveau 3)**.

## Structure du projet
- `index.html` : Structure principale et sections du portfolio (Accueil, À propos, Compétences, Projets, Contact).
- `style.css` : Feuille de style moderne (thème sombre, responsive desktop & mobile).
- `script.js` : Gestion interactive du menu de navigation mobile.

## Visualisation
Ouvrir simplement le fichier `index.html` dans n'importe quel navigateur web (Chrome, Edge, Firefox).
